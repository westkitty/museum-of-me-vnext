# Museum of Me: 200 externally sourced GLB candidates

**Date:** 2026-11-11. **Status:** read-only, screened candidates; not downloaded, imported, or runtime-approved.

## The evidence, precisely

- **200 unique pre-existing `.glb` files** selected from 15 Kenney-derived packs, and mapped to all 35 currently defined exhibits plus the Rotunda, island, theater, and Dexter Sanctuary.
- **Size metadata:** 200 GitHub `catalog.json` file-size values matched the paths and byte sizes in the recursive `main` Git tree on 2026-11-11. Largest 263,780 bytes (257.6 KiB). Sum 5,066,036 bytes (4.83 MiB). Neither number is a GPU-memory or download-build-budget benchmark.
- **Rights evidence:** The repackaged collection states all models are Kenney CC0; the included LICENSE confirms its converted GLBs are CC0. The original Kenney pack pages also display CC0. Reconfirm license evidence at import/release.
- **Immutable link pin:** `3ddcc695adbba9fb918cf31b7c139b3f95b76910`; an individual model link opens the exact file at that revision, not a changing `main` pointer.
- **Self-contained claim:** Source README calls the GLBs self-contained and textures embedded; the 200 files have **not** individually been opened or validated against GLTFLoader. A file that fits the byte limit may still have a loader-extension, texture, orientation or visual-quality issue.
- **No download was made and no museum or GitHub file was changed.**

## Builder limitations to address later

- The current Builder accepts local, self-contained glTF 2.0 `.glb` input up to 8 MiB, with source-side SHA256 naming and stored provenance. Importing files is a dev-only localhost process, not a public asset upload.
- The shared workshop authoring manifest is capped at **256 additional authored placement records**, not a ceiling on library entries or the entire world geometry. The next implementation chat should redesign this for many thousands while keeping save/conservation/collision and GPU budgets honest.
- The runtime Builder currently constructs a basic GLTFLoader for these placements. Avoid compressed extension-dependent files unless decoder support is verified/added deliberately.
- A placed GLB is an inert model by default. It does not implement interactive logic, character AI, working audio, doors, seating, or a reliable collision shape without separate authoring.
- **Important:** Existing installations, official Starsilk/Drakken canon, authored Dexter identity, museum architecture, protected paths, and real exhibits must not be overwritten by generic stock props. This is a decor/illustration candidate shelf, not a museum replacement plan.

## Not solved by this model shelf

- Authentic microphone, recording console, film projector, server cabinet, and specialist scientific apparatus designs may require a separate high-fidelity search; the selected Kenney items mostly provide supporting furniture and symbolic objects.
- Canonical animal/human character designs, Starsilk/Drakken forms, and existing user-authored exhibit artifacts remain governed separately. `cube-pets/animal-dog` and `cube-pets/animal-cat` must never be presented as Dexter or Westcat.
- The island already owns its terrain, navigation, water, vegetation, and wildlife systems. New nature GLBs should be candidates only for carefully reviewed dressing/variants; mass spawning needs instancing/spatial budgets.
- A few candidates are deliberately stylized or miniature/game-like. Their best home may be inside a game exhibit, not in the central editorial galleries.
- Rights screening and file existence do not mean the downloaded GLBs were individually binary-inspected, opened in Blender, run through the Builder, or approved for public display.

## Suggested next implementation action

In a separate explicitly authorized implementation chat, use the companion JSON ledger as the discovery manifest, inspect/import a small pilot across multiple wings, preserve provenance and local-only limits, and redesign the shared 256-placement cap based on actual storage, collision, streaming and rendering tests. Never bulk-import all 200 solely because they were screened here.
